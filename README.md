# codomax-day23-kmeans-clustering
# Codomax AI/ML Internship – Day 23

## Project
K-Means Clustering

## Description

This project demonstrates K-Means Clustering, an unsupervised
machine learning algorithm used to group similar data points.

Student data is grouped into three clusters based on study hours,
attendance, and previous academic score.

## Features

- Study Hours
- Attendance
- Previous Score

## Concepts Covered

- Unsupervised Learning
- K-Means Clustering
- Feature Scaling
- StandardScaler
- Cluster Assignment
- Cluster Centers
- Data Grouping

## Technologies

- Python
- Pandas
- NumPy
- Scikit-learn

## Run

```bash
pip install -r requirements.txt
python main.py
```

## Learning Outcome

Learned how K-Means can automatically group similar observations
without requiring predefined target labels.
